# Local Delivery App

Android-based local delivery marketplace connecting
customers with nearby shops.

## Features

- Customer and shopkeeper roles
- Shop-wise products
- Add to cart
- Quantity management
- Order placement
- Order tracking
- Room database
- Jetpack Compose UI
- Kotlin Coroutines

## Tech Stack

Kotlin
Jetpack Compose
Room
Coroutines
MVVM
Navigation
